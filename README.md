Traffic Violation Detection using Car Dash Camera
Project Overview
This project uses video footage captured from a car's dash camera to automatically detect traffic violations such as running red lights, illegal turns, speeding, and lane violations. By leveraging computer vision and machine learning techniques, the system analyzes live or recorded videos to identify violations and alert the driver or log the incidents.

Features:-
Real-time detection of common traffic violations.
Supports processing of live video feed or recorded dashcam footage.
Alerts or logs violations with timestamps and video snapshots.
Detects vehicles, traffic signals, and lane markings using object detection and image processing.
Extensible to add more violation types and enhance accuracy.
